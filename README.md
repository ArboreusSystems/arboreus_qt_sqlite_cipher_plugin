Arboreus Sqlite Cipher plugin for Qt 6+ mobile iOS or Android applications
====================

This is redeveloped fork of https://github.com/devbean/qtciphersqliteplugin
This plugin tested with Qt 6.12 framework for using it on iOS, Android and MacOS
Under the hood of this plugin Sqlite3MC v3.54.1 library.https://github.com/utelle/SQLite3MultipleCiphers. Sqlite3MC library under the MIT license.
